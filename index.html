Learn Microsoft Power Platform & Power BI, from zero.

Twenty days, and one project you keep building the whole way through. Everything in your web browser — no software to install, nothing that needs a powerful laptop. Each day explains the why in plain English and the how click-by-click, with diagrams. By Day 20 you'll have a complete Community Library ecosystem — data, apps, automation, a chatbot, and a Power BI report — that is yours.

How to use this course

Do one day at a time. A "day" is roughly 60–120 minutes — split it across a morning and evening if you like. You don't have to finish in 20 calendar days; the number just means there are 20 lessons, grouped into six phases (use the menu on the left).

The kinds of boxes you'll see
  • Concept (blue) — the idea explained simply, then a little more technically, often with a diagram.
  • Do this (green) — the exact clicks, with checkboxes that remember your progress.
  • Tip (yellow) — something handy or a shortcut.
  • Careful (red) — something that could cost money or cause a mistake. Read these.
  • Words you learned (purple) — a mini-dictionary for the day.
  • Check yourself (teal) — a tiny quiz to confirm it stuck.
Tip — your progress is saved When you tick a checkbox, this page remembers it on this computer and browser (even after you close it). The bar in the top-left fills as you go. Progress is saved per page, so each phase keeps its own ticks. A different computer won't have your ticks — that's normal.
Careful — two golden rules for the whole course
  1. Only ever use made-up ("fake") data. Names, emails, numbers — invent them all. Never type in real personal or work information from anyone.
  2. Only build in your dedicated learning environment (set up on Day 0). If you used the Power Apps Developer Plan, your environment is named after you — e.g. "Ashwini Pandey's Environment". If an admin created it for you, it may be called "Learning". Either way, always confirm the environment picker (top-right) shows the right one before building anything.

Your project: the Community Library

This course is not a set of unrelated exercises. From Day 2 onward you build one real thing — a Community Library — and it grows a little every day. By the end it's a complete, connected ecosystem: a database, apps people use, automations that run by themselves, a chatbot, and a Power BI report — all sharing the same data. It becomes a project that is genuinely yours, and something you can show people.

Day 0

Setup — done once, by the account owner

For the person who owns the Microsoft 365 & Azure trials · ~20 minutes

Concept — what you're setting up and why

Plain English: the trials belong to one person (the "account owner"). Before the learner starts, the owner makes the learner their own sign-in and their own private room to build in, so the learner can't accidentally disturb anything else.

A bit more technical: in Microsoft's cloud, one company/trial is a tenant. Inside a tenant you create users (people who can sign in) and environments (separate containers that each hold their own apps and database). We give the learner a user account and a dedicated environment called Learning.

Do this — set up the learner's environment (two paths)

Path A — Power Apps Developer Plan (recommended, free & instant)

  • The learner goes to powerapps.microsoft.com/developerplan and signs in with their Microsoft account (a personal Outlook/Hotmail, or the E5 learner account). Click Get started free. Microsoft creates a personal environment automatically — it will be named "[Learner's Name]'s Environment" (e.g. "Ashwini Pandey's Environment").
  • The learner opens make.powerapps.com in an incognito window, signs in, and confirms the environment picker (top-right) shows their Developer Plan environment. That's their building room for all 20 days.

Path B — Admin creates a shared "Learning" environment (requires M365 admin)

  • Go to admin.microsoft.com → Users → Active users → Add a user. Create learner@YOURTENANT.onmicrosoft.com, set a password, assign a Microsoft 365 / Office 365 E5 licence.
  • Go to admin.powerplatform.microsoft.com → Environments → New. Name it Learning, pick your region, set Add a Dataverse data store = Yes. (If you see a capacity error, activate the Power Apps Premium trial in the M365 admin centre first — Billing → Purchase services → Power Apps Premium → free trial.)
  • Open Learning → Settings → Users + permissions → Users, add the learner, give them System Administrator for this environment only.

Both paths:

  • Share the sign-in with the learner; tell them to always use a private / incognito window.
  • Azure (only for Day 16's short tour): plan to sit with the learner using the owner's Azure sign-in. Keep Azure supervised — it can cost money.
Careful — money lives in Azure, not in Power Platform Days 1–15 and the Power BI track are covered by the trial and create no surprise charges. The short Azure tour on Day 16 is the only place that can bill — we keep it tiny, never create a "virtual machine", and delete everything at the end.

Keep your project forever (read this early)

Important — the trial doesn't last, so plan ahead

The Microsoft 365 trial eventually ends. When it does (or if it's cancelled), the tenant is disabled and later deleted — and the running project (apps, flows, tables, reports) goes with it, because it lives in Microsoft's cloud. The good news: you can preserve everything and even keep it running for free, forever. Two layers:

Layer 1 — back it up to files you own

These files are yours permanently, on your computer:

  • The solution — export My Learning Solution as an unmanaged .zip (Day 16). It contains your tables, apps, and flows.
  • The data — export table rows to Excel/CSV (from each table's grid → Export).
  • The Power BI report — save it as a .pbix file (Power BI Desktop), or download it from the Service.
Layer 2 — keep it running for free (the Developer Plan)

The Power Apps Developer Plan (powerapps.microsoft.com/developerplan) is free forever, no card, no expiry, and includes its own Dataverse environment. You import your exported solution there and the whole project keeps working — canvas app, flows, tables, chatbot, and Power BI (free tier for personal use).

The one catch: the Developer Plan must live on an account that survives the trial — not the learner account created inside the trial tenant. So either sign up for the Developer Plan with a separate personal account, or do the export + import before the trial ends. If in doubt, get a Developer Plan early and build a habit of exporting your solution each week.

In one line The trial's copy won't survive cancellation — but export your solution + data + .pbix, and import into a free Developer Plan, and your Community Library is yours to keep and keep using. Day 16 and Day 20 walk you through it.
